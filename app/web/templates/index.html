使用指引 本系统只做「读合同 → 挑毛病 → 把意见写回审批系统」，不替人做通过/驳回决定
  1. 拉取　点下方「拉取待处理审批单」，把审批系统里等你审的合同拿过来。 重复点不会建重复任务（按审批编号去重）。
  2. 处理　在列表里点某份合同的「查看详情」，进去后点「一键处理」。 系统会自动下载文件 → 读文档（扫描件约 5—7 秒）→ 跑 26 条规则 → 生成意见 → 写回评论区。
  3. 核对　详情页从上往下依次是：审批与附件 → 解析结果（读到了什么）→ 规则命中（挑出什么问题，带原文证据）→ 结果与回写（最终意见）。
  4. 遇到「已阻塞」　说明有技术问题卡住了，点进去看阻塞原因。 附件缺失 / 文件为空 / 无法识别 → 让对方补文件，再点「重试阻塞任务」→「重新处理」。
